## ⚠️ 项目路径与中文路径问题（重要）

- **真实项目路径：`F:\zcode\tutoring-manager`（纯 ASCII）**，所有构建、测试、git 操作都在此进行。
- 项目最初位于 `F:\zcode\课程表`（含中文）。中文 Windows 的 GBK 系统编码与工具链冲突：AGP 直接拒绝在非 ASCII 路径构建；即使强制跳过检查，**Gradle 测试 worker 进程也无法从非 ASCII 路径加载测试类**（`ClassNotFoundException`）。已验证无效的软件级方案：`android.overridePathCheck=true`、Test 任务 jvmArgs 强制 UTF-8、ASCII 名称目录 junction（Java 规范路径会解析回真实中文路径）。
- **结论：永远不要把本项目移回含非 ASCII 字符的路径。**
- 原中文路径现残留一个被会话进程占用的**空目录**，会话结束后可手动删除；如需保留旧名入口，可执行：
  `cmd /c mklink /J F:\zcode\课程表 F:\zcode\tutoring-manager`

## 模拟器（首选测试环境，2026-09-28 就绪）

- **用户偏好：验证工作一律在模拟器内进行，不使用真机**。
- 加速驱动：**AEHD 2.2**（AMD CPU 可用，无需 WHPX/Hyper-V、无需重启）。检查命令：`emulator -accel-check` 应显示 "installed and usable"。首次安装需一次管理员确认（silent_install.bat）。
- 系统镜像：`system-images;android-36;google_apis;x86_64`；AVD：`keshi_test`。
- 启动：`%LOCALAPPDATA%\Android\Sdk\emulator\emulator.exe -avd keshi_test`，或 Android Studio → Device Manager。
- 开机约 25 秒（Ryzen 5 9600X + AEHD）；`adb install` 前注意用 `-s emulator-5554` 指定目标，避免与真机混淆。
- **拼音输入法：fcitx5-android 0.1.3 + rime 插件**（2026-09-29 安装，GitHub Releases 直下 APK，完全离线）。键盘空格左侧 🌐 键切换 English / Pinyin。其余方案均不可用：Gboard 中文词典需连 Google 下载（被墙，字母直出无组词）；Trime 同文输入法在 API 36 上有主题部署崩溃 bug（No valid theme available）。

## 常用命令（项目根目录，Git Bash）

```bash
./gradlew :app:assembleDebug        # 构建调试 APK → app/build/outputs/apk/debug/
./gradlew :app:testDebugUnitTest    # 运行单元测试 → app/build/reports/tests/
./gradlew :app:assembleRelease      # 构建正式包（M5 前暂不签名）
```
