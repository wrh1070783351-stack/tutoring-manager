# 开发环境说明

> M0 阶段（2026-09-27）搭建完成时的环境快照，重装/换机时按此恢复。

## ⚠️ 项目路径与中文路径问题（重要）

- **真实项目路径：`F:\zcode\tutoring-manager`（纯 ASCII）**，所有构建、测试、git 操作都在此进行。
- 项目最初位于 `F:\zcode\课程表`（含中文）。中文 Windows 的 GBK 系统编码与工具链冲突：AGP 直接拒绝在非 ASCII 路径构建；即使强制跳过检查，**Gradle 测试 worker 进程也无法从非 ASCII 路径加载测试类**（`ClassNotFoundException`）。已验证无效的软件级方案：`android.overridePathCheck=true`、Test 任务 jvmArgs 强制 UTF-8、ASCII 名称目录 junction（Java 规范路径会解析回真实中文路径）。
- **结论：永远不要把本项目移回含非 ASCII 字符的路径。**
- 原中文路径现残留一个被会话进程占用的**空目录**，会话结束后可手动删除；如需保留旧名入口，可执行：
  `cmd /c mklink /J F:\zcode\课程表 F:\zcode\tutoring-manager`

## 常用命令（项目根目录，Git Bash）

```bash
./gradlew :app:assembleDebug        # 构建调试 APK → app/build/outputs/apk/debug/
./gradlew :app:testDebugUnitTest    # 运行单元测试 → app/build/reports/tests/
./gradlew :app:assembleRelease      # 构建正式包（M5 前暂不签名）
```
