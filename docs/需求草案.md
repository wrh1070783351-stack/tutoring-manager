# 需求草案（v1）

> 状态：草稿，随讨论持续更新。最后更新：2026-09-27

## 1. 项目概述

| 项目 | 说明 |
|---|---|
| 目标用户 | 补习班老师本人（单人使用） |
| 平台 | Android 手机 App |
| 数据存储 | 手机本地（离线可用），无服务器、无账号系统 |
| 技术栈 | Kotlin + Jetpack Compose（Material 3）+ Room 数据库 |

核心问题：用手工表格管理学生课时和缴费容易出错、难汇总。本 App 集中管理**学生档案、课时包/学期报名、消课记录、缴费记录、课程表**，并自动算出每个学生的剩余课时。

## 2. 业务概念与数据模型

```
学生 Student ──报名 Enrollment──> 班级 Class
                                    │
                                    ├──每周固定课表（如周六 10:00-12:00）
                                    └──临时变动（约课/调课/停课）

报名 Enrollment（学生在某班级的报读关系）分两种计费类型：
  ├─ 次卡制：持有课时包（次数、金额、购买日期、可选有效期），上一次课扣 1 次
  └─ 学期制：按期缴费（起止日期、金额），有效期内上课不扣次数

消课记录 Attendance：某日某班上课时逐个学生标记（到课/请假/缺勤）
缴费记录 Payment：金额、日期、方式、备注，可关联课时包或学期报名
```

- **剩余课时** = 该学生该班级所有课时包剩余次数之和；学期制学生显示「有效期至 x 月 x 日」。
- 一个学生可同时报多个班级；一个班级可同时有次卡制和学期制学生。

## 3. 功能需求（第一版）

### 3.1 学生管理
- 学生档案：姓名、年级、家长电话、微信号、备注；增删改查、搜索
- 学生详情页：所报班级、各班剩余课时、缴费历史、消课历史

### 3.2 班级与课程表
- 班级管理：班级名（如「初二数学周六班」）、科目、状态（开班/结班）
- 每周固定课表：一个班级可设多个上课时间段
- 周视图课程表：按周查看每天要上哪些班；**临时约课**（某日加一节）、调课、停课登记
- 「今日课表」为 App 首页，直达点名

### 3.3 报名、课时包与缴费
- 给学生报班，选择计费类型（次卡 / 学期）
- 次卡购买与续费：次数、赠送次数、金额、购买日期、可选有效期
- 学期报名与续费：起止日期、金额
- 缴费记录列表（按学生/按时间筛选），本月收入汇总

### 3.4 点名与消课
- 从今日课表进入班级点名界面，批量标记：**到课 / 请假 / 缺勤**
- 到课自动扣 1 课时（次卡制学生）；学期制学生在有效期内不扣次数
- 课时不足的学生在点名界面上高亮提醒
- 消课记录可撤销/修改（留操作痕迹）

### 3.5 提醒（第一版为 App 内提醒，不做推送）
- 打开 App 首页提示：课时不足名单（默认剩余 ≤ 3 次，阈值可设置）、课时包/学期即将到期名单

### 3.6 统计与数据安全
- 统计页：在读人数、本周消课数、本月/本年收入
- 导出：学生课时余额表、缴费明细导出 CSV/Excel
- 一键备份 / 恢复（备份文件可存到微信、网盘等任意位置）

### 3.7 明确不做（第一版排除）
- 家长端、微信小程序 ❌
- 多老师账号、多设备云同步 ❌（数据模型设计时预留升级空间）
- 在线收款（微信/支付宝支付），只做记录 ❌
- iOS 版本 ❌

## 4. 非功能需求

- 完全离线可用，不申请网络权限（学生个人信息不出手机，隐私合规最简单）
- 点名操作 ≤ 3 步完成（首页 → 班级 → 批量标记）
- 数据防丢：本地数据库 + 手动一键备份；建议每周导出一次备份
- 最低支持 Android 8.0（API 26），覆盖近十年绝大多数手机

## 5. 待确认问题

1. **旧数据**：现有的 Excel 学生/缴费表，需要我写导入功能吗？（需要的话发一份样表）
2. **请假规则**：学生请假扣不扣课时？默认「不扣、可约补课」，按你们实际规则改。
3. **补课**：请假的课需要补课登记功能吗？
4. **提醒阈值**：剩余几次算「课时不足」？默认 3 次。
5. **App 名称**：定一个，影响应用图标和安装后显示名。

## 6. 里程碑

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| M0 | 开发环境搭建 + 项目骨架 | 空壳 App 能安装到手机运行 |
| M1 | 学生管理 + 班级/课程表管理 | 能录入真实学生和班级，周视图正确显示 |
| M2 | 报名 + 课时包 + 缴费记录 | 买卡、报学期、续费全流程可走通 |
| M3 | 点名消课 + 今日课表 | 一节真实课的点名消课可完成，余额准确 |
| M4 | 提醒 + 统计 + 导出/备份 | 课时不足名单正确，备份可恢复 |
| M5 | 打包 APK，装进你的手机，用真实数据试用 1-2 周 | 你本人确认可用 |
